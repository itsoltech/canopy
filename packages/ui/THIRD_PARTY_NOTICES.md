## Tabler outline icons

`src/icons.ts` contains outline path geometry from **@iconify-json/tabler 1.2.43**,
`icons.json`. Source: https://www.npmjs.com/package/@iconify-json/tabler/v/1.2.43
and https://github.com/tabler/tabler-icons (https://tabler.io/icons).
The bundled geometry uses a 24-unit viewBox; Canopy renders it at stroke width 2.25.
Provider and connector brand marks are separate from this icon family.
